# Ibn-e-Sina Sports Fest 2026

A responsive static website concept for Ibn-e-Sina Sports Fest 2026. Includes the supplied school logo.

## Files
- `index.html` — complete site markup and styles
- `assets/school-logo.jpg` — converted copy of the uploaded school logo

## Preview
Open `index.html` in a browser.

## Deploy on GitHub + Vercel
1. Create a GitHub repository named `ibn-e-sina-sports-fest-2026`.
2. Upload `index.html`, the `assets` folder, and this `README.md` (keep the folder structure).
3. Commit the files.
4. On Vercel, choose **Add New → Project**, import the GitHub repository.
5. This is a static HTML site: no framework preset or build command is required. Deploy.
6. After changes are committed to GitHub, Vercel can redeploy automatically.

## Important
This is a fresh recreation, not a pixel-perfect copy of the original Replit site because its actual frontend source was not included in the files provided. Dates, fixtures, team lists, scores and contact details are intentionally not invented. Confirm the official school name, permissions, and event details before sharing publicly.
